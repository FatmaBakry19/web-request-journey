# Instagram Request Journey

## What is this project?

In this task, I chose Instagram and created a simple diagram that explains what happens when I open Instagram from my browser.

The diagram shows the main steps that a request goes through from the client to the server and back.

## How does the Request work?

When I type `instagram.com` in my browser and press Enter, several things happen:

1. **Client**
   My browser is the client. It sends a request to access Instagram.

2. **DNS**
   The browser needs to know the IP address of the Instagram server. DNS translates the domain name `instagram.com` into an IP address.

3. **Network**
   After getting the IP address, the request travels through the network to reach the Instagram server.

4. **Instagram Server**
   The server receives the request and processes it.

5. **Response**
   The server sends a response back to the client.

6. **Browser**
   The browser receives the response and displays the Instagram website.

## Diagram

**Client → DNS → Network → Instagram Server → Response → Client**

## What I Learned

From this task, I learned the basic journey of a web request and understood the roles of the Client, DNS, Network, Server, and Response.
